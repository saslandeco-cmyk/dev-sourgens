# Bois & Forêt — prototype scierie B2C

Prototype léger de présentation client en Next.js, React et TypeScript.

## Lancer dans VS Code
Prérequis : Node.js LTS récent.
1. Décompresser le ZIP.
2. Ouvrir le dossier dans VS Code.
3. Dans le terminal intégré, lancer :

```bash
npm install
npm run dev
```

4. Ouvrir http://localhost:3000

Vérification de compilation : `npm run build`.

## Ce qui est inclus
- Page d'accueil responsive et identité visuelle bois/scierie.
- Catalogue filtrable par catégorie.
- Présentation du savoir-faire et étapes du projet.
- Formulaire de demande de devis qui présélectionne un produit.
- Confirmation simulée : aucun e-mail n'est envoyé et aucune donnée n'est stockée.

## À personnaliser avant publication
- Nom, logo, coordonnées, horaires et zone de livraison.
- Produits, essences, sections, tarifs, stock et conditions de retrait/livraison.
- Remplacer les photos externes par les photos réelles de la scierie.
- Connecter le formulaire à un e-mail ou CRM avec validation et anti-spam.
- Ajouter les pages légales et mettre en place SEO local et mesure des conversions.

Les prix sont fictifs et servent uniquement à la démonstration.
